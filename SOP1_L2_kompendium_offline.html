SOS · 02

Co naprawdę jest w L2?

↑

Oparte na materiałach 2026 w repozytorium SOP-MINI, nie na starszej wersji witryny z inną numeracją.

A · obowiązkowa baza

open, close, read, write, lseek, flagi, uprawnienia, deskryptor.

B · sedno laboratorium

poll, fcntl, O_NONBLOCK, FIFO, EAGAIN, readv, writev, mmap.

C · pomocniczo

stat/fstat, buforowanie stdio i elementy L1. timerfd i epoll: materiał dodatkowy.

Oficjalne zadanie treningowe L2 sop-cake obejmuje 4 etapy: plik 2048 B, FIFO, składanie linii, poll i mmap. Podobny typ umiejętności nie oznacza identycznego zadania na ocenę.

Skoncentruj się na obsłudze strumieni i błędów, a nie na zapamiętywaniu kilkudziesięciu funkcji. Jedno read nie musi dać całej wiadomości, a jeden write nie musi zapisać wszystkiego.

Szkielet C i kompilacja

PROSTY WZORZEC · PEŁNY PROGRAM
Prosty start programu
#define _POSIX_C_SOURCE 200809L
#include <errno.h>
#include <fcntl.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>

int main(int argc, char **argv) {
    if (argc != 3) {
        fprintf(stderr, "Użycie: %s wejście wyjście\n", argv[0]);
        return EXIT_FAILURE;
    }

    int fd = open(argv[1], O_RDONLY);
    if (fd == -1) {
        perror("open wejście");
        return EXIT_FAILURE;
    }

    if (close(fd) == -1) {
        perror("close");
        return EXIT_FAILURE;
    }
    return EXIT_SUCCESS;
}

Błędy w C: perror, errno, strerror

↑

Najprostszy schemat wystarcza w większości zadań. Przypadków szczególnych ucz się osobno.

PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
Najprostsza poprawna obsługa błędu
Fragment wewnątrz main; wymagane errno.h, fcntl.h, stdio.h, stdlib.h, unistd.h.
int fd = open("dane.bin", O_RDONLY);

    perror("open dane.bin"); // wypisuje również przyczynę z errno

}
WERSJA ODPORNIEJSZA · FRAGMENT DO WKLEJENIA
Gdy chcę sam sformatować komunikat
Wymaga string.h i errno.h. strerror jest przydatny, gdy potrzebujesz własnego tekstu.
int fd = open("dane.bin", O_RDONLY);
if (fd == -1) {
    int saved_errno = errno; // zachowaj przed innymi wywołaniami
    fprintf(stderr, "Nie otwarto dane.bin: %s (errno=%d)\n",
            strerror(saved_errno), saved_errno);
    return EXIT_FAILURE;
}
PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
Prosta funkcja die(), którą łatwo wkleić
Fragment: ostatnia linia musi znajdować się wewnątrz funkcji, nie po definicji die().
#include <stdio.h>
#include <stdlib.h>
static void die(const char *where) {
    perror(where);
    exit(EXIT_FAILURE);
}
/* użycie po wykrytym błędzie syscalla: */
if (fd == -1) die("open");
Istotne: errno ma znaczenie, gdy funkcja zgłosiła błąd. Nie sprawdzaj go po sukcesie, bo może pamiętać wcześniejszy błąd. perror musi być wywołane blisko miejsca błędu, zanim inne wywołania zmienią errno.
BLEDY · 06

Który błąd wymaga jakiej reakcji?

↑

EOF i EAGAIN są normalnymi stanami. EINTR często oznacza „spróbuj ponownie”.

Stan / errnoProsta interpretacjaCo zrobić
read() > 0Odebrano tyle bajtówPrzetwórz dokładnie n
read() == 0EOF, koniec strumieniaZamknij / przestań czytać; przy FIFO rozważ cykl życia pisarzy
EINTRPrzerwane sygnałemZwykle ponów operację
EAGAIN / EWOULDBLOCKBrak danych terazNie spinuj; użyj poll
ENOENTPlik/element ścieżki nie istniejeSprawdź ścieżkę, cwd, argv
EEXISTJuż istniejePrzy O_EXCL/mkfifo określ, czy to akceptowalne
EACCES / EPERMBrak uprawnieńSprawdź tryb i prawa katalogów
EBADFZły/zamknięty fd lub trybSprawdź fd>=0 i O_RDONLY/WRONLY
ESPIPENie da się ustawić offsetuNie rób lseek na FIFO/pipe
EPIPEZapis do pipe bez czytelnikaObsłuż błąd oraz możliwy SIGPIPE
EINVALNiedozwolone argumentySprawdź flagi, długości, offsety

Zasada praktyczna: nie każda sytuacja z read == -1 powinna kończyć program. Nie traktuj EAGAIN jak awarii.

FUNDAMENTY · 08

read() · odczyt / EOF / krótkie wyniki

↑

Najprostsze czytanie danych z pliku lub FIFO. Nie zakładaj, że czytasz od razu cały komunikat.

PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
Prosta pętla odczytu
Dobrze ilustruje podstawy, ale w odpornej wersji obsłuż EINTR oraz krótkie write.
char buf[4096];
for (;;) {
    ssize_t n = read(fd, buf, sizeof(buf));
    if (n == 0) break;          // EOF
    if (n == -1) die("read");   // wersja dla blokującego fd
    /* użyj DOKŁADNIE pierwszych n bajtów bufora */
    if (write(STDOUT_FILENO, buf, (size_t)n) == -1)
        die("write stdout");   // prosty wariant, bez krótkich zapisów
}
WERSJA ODPORNIEJSZA · FRAGMENT DO WKLEJENIA
Odporniejszy read: EINTR + EAGAIN
ssize_t n = read(fd, buf, sizeof(buf));
if (n > 0) {
    /* odebrano n bajtów */
} else if (n == 0) {
    /* EOF */
} else if (errno == EINTR) {
    /* spróbuj odczytać ponownie */
} else if (errno == EAGAIN || errno == EWOULDBLOCK) {
    /* brak danych: poll(), nie busy waiting */
} else {
    die("read");
}
read zwraca bajty, nie C-string. printf("%s", buf) jest niebezpieczne, gdy nie dodasz zera. Dla surowych danych używaj write/fwrite z liczbą bajtów.
FUNDAMENTY · 09

write() · zapis i krótkie zapisy

↑

Najważniejsza pułapka: wynik nie musi być równy trzeciemu argumentowi.

PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
Jednorazowy krótki zapis (prosty przykład)
const char text[] = "OK\n";
ssize_t n = write(fd, text, sizeof(text) - 1);
if (n == -1) die("write");
if (n != (ssize_t)(sizeof(text) - 1)) {
    fprintf(stderr, "Niepełny zapis\n");
}
WERSJA ODPORNIEJSZA · FRAGMENT DO WKLEJENIA
Funkcja write_all, którą warto mieć w każdym zadaniu
Dla blokujących deskryptorów. Przy O_NONBLOCK trzeba dodatkowo reagować na EAGAIN, zwykle przez poll.
static void write_all(int fd, const void *data, size_t len) {
    const unsigned char *p = data;
    while (len > 0) {
        ssize_t n = write(fd, p, len);
        if (n > 0) {
            p += n;
            len -= (size_t)n;
        } else if (n == -1 && errno == EINTR) {
            continue;
        } else {
            if (n == 0) errno = EIO;
            die("write");
        }
    }
}
Jeśli w kodzie piszesz write(fd, buf, strlen(buf)), pamiętaj, że to ma sens tylko przy poprawnym stringu, nie przy danych binarnych. Przy binariach użyj dokładnie rozmiaru danych.
FUNDAMENTY · 10

close() · kończenie pracy

↑

Deskryptor jest zasobem procesu. Zwolnij go na każdej ścieżce.

PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
Minimalny wzorzec
if (close(fd) == -1) {
    perror("close");
    return EXIT_FAILURE;
}
fd = -1;  // nie użyj go przypadkiem drugi raz
W Linuxie nie ponawiaj ślepo close() po EINTR, bo numer fd mógł już zostać zwolniony i przydzielony ponownie. Przy wielu zasobach użyj pojedynczego bloku cleanup z goto.
BLEDY · 11

Dobre praktyki: cleanup bez chaosu

↑

Gdy masz kilka deskryptorów, wyjście w połowie funkcji może powodować wycieki zasobów.

WERSJA ODPORNIEJSZA · FRAGMENT DO WKLEJENIA
Odporny wzorzec goto cleanup
Fragment wewnątrz funkcji int ...(...). src i dst są jej argumentami.
int in = -1, out = -1;
int result = EXIT_FAILURE;
in = open(src, O_RDONLY);
if (in == -1) { perror("open src"); goto cleanup; }
out = open(dst, O_WRONLY | O_CREAT | O_TRUNC, 0644);
if (out == -1) { perror("open dst"); goto cleanup; }
/* ... kod ... */
result = EXIT_SUCCESS;
cleanup:
    if (out != -1 && close(out) == -1) {
        perror("close dst"); result = EXIT_FAILURE;
    }
    if (in != -1 && close(in) == -1) {
        perror("close src"); result = EXIT_FAILURE;
    }
    return result;
To jest właśnie przypadek, gdzie goto ma sens w C. Nie ma potrzeby tworzyć własnego mini-frameworka od obsługi błędów na laboratorium.
FUNDAMENTY · 12

Kopiowanie pliku · kompletny program

↑

Gdy zadanie wymaga dwóch ścieżek i niskopoziomowego I/O.

WERSJA ODPORNIEJSZA · PEŁNY PROGRAM
copy.c: gotowy odporny przykład
#define _POSIX_C_SOURCE 200809L
#include <errno.h>
#include <fcntl.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>
#include <unistd.h>
static void die(const char *s) { perror(s); exit(1); }
static void write_all(int fd, const char *p, size_t len) {
    while (len) {
        ssize_t n = write(fd, p, len);
        if (n > 0) { p += n; len -= (size_t)n; }
        else if (n < 0 && errno == EINTR) continue;
        else die("write");
    }
}
int main(int argc, char **argv) {
    if (argc != 3) {
        fprintf(stderr, "Użycie: %s src dst\n", argv[0]); return 1;
    }
    int src = open(argv[1], O_RDONLY);
    if (src == -1) die("open src");
    struct stat a, b;
    if (fstat(src, &a) == -1) die("fstat");
    if (stat(argv[2], &b) == 0) {
        if (a.st_dev == b.st_dev && a.st_ino == b.st_ino) {
            fprintf(stderr, "Źródło i cel to ten sam plik\n");
            close(src); return 1;
        }
    } else if (errno != ENOENT) die("stat dst");
    int dst = open(argv[2], O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (dst == -1) die("open dst");
    char buf[4096];
    for (;;) {
        ssize_t n = read(src, buf, sizeof(buf));
        if (n == 0) break;
        if (n == -1) {
            if (errno == EINTR) continue;
            die("read");
        }
        write_all(dst, buf, (size_t)n);
    }
    if (close(dst) == -1) die("close dst");
    if (close(src) == -1) die("close src");
    return 0;
}
PROSTY WZORZEC · SKRYPT TERMINALA
Sprawdź czy kopia identyczna
gcc -std=c11 -Wall -Wextra -Wpedantic -g copy.c -o copy
printf 'abc\000xyz\n' > src.bin
./copy src.bin dst.bin
cmp src.bin dst.bin && echo 'Kopia OK'
Oficjalny dydaktyczny kod l2-1.c to krótszy wariant. Własna wersja dodaje O_TRUNC, obsługę krótkich zapisów i ochronę przed kopiowaniem pliku na samego siebie.

lseek() · pozycja w pliku

Dla plików o stałej długości rekordów. Na FIFO lseek nie działa.

PLIKI · 16

readv / writev · wiele buforów

↑

W tutorialu L2 baza zawiera rekordy: 4 bajty unsigned int i 64 bajty tytułu.

PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
Proste writev: jeden rekord 68 B
#include <sys/uio.h>
unsigned int size = 100;
char title[64] = {0};
strcpy(title, "Przyklad");
struct iovec v[2] = {
    { .iov_base = &size,  .iov_len = sizeof(size) },
    { .iov_base = title, .iov_len = sizeof(title) }
};
ssize_t n = writev(fd, v, 2);
if (n == -1) die("writev");
if (n != 68) fprintf(stderr, "Krótki writev\n");
/* zakładamy, że sizeof(unsigned int) == 4 */
WERSJA ODPORNIEJSZA · FRAGMENT DO WKLEJENIA
readv: każdy rekord do osobnego bufora
Fragment: N to liczba rekordów; sprawdź, że rozmiar pliku dzieli się przez 68, N mieści się w IOV_MAX, a sizeof(unsigned int)==4.
/* N rekordów po 68 B; plik ma długość N*68 */
typedef struct { unsigned int size; char title[65]; } Book;
Book *books = calloc(N ? N : 1, sizeof(*books));
struct iovec *v = calloc(N ? N : 1, sizeof(*v));
if (!books || !v) die("calloc");
for (size_t i = 0; i < N; ++i) {
    v[i].iov_base = &books[i];
    v[i].iov_len = 68;       // NIE sizeof(Book)!
    books[i].title[64] = '\0';
}
ssize_t n = readv(fd, v, (int)N);
if (n == -1) die("readv");
if (n != (ssize_t)(68*N)) {
    fprintf(stderr, "Krótki odczyt bazy\n");
}
free(v);
free(books);
Uwaga na najczęstszy błąd: sizeof(Book) może być większe niż 68. iov_len ma opisywać długość rekordu na dysku, nie długość struktury w pamięci. W ogólnym programie krótkie readv/writev trzeba obsłużyć, przesuwając granice iovec.
PLIKI · 17

mmap · plik jako tablica pamięci

↑

Używaj, gdy trzeba wielokrotnie czytać lub modyfikować plik w miejscu.

PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
Najprostsze mapowanie do odczytu
struct stat st;
if (fstat(fd, &st) == -1) die("fstat");
if (st.st_size == 0) {
    fprintf(stderr, "Pusty plik\n");
    return EXIT_FAILURE;
}
size_t len = (size_t)st.st_size;
char *p = mmap(NULL, len, PROT_READ, MAP_PRIVATE, fd, 0);
if (p == MAP_FAILED) die("mmap");
/* p[0] ... p[len - 1] */
if (munmap(p, len) == -1) die("munmap");
WERSJA ODPORNIEJSZA · FRAGMENT DO WKLEJENIA
Modyfikacja raw~berries → raspberries
/* fd otwarty O_RDWR, plik ma len > 0 bajtów */
char *p = mmap(NULL, len, PROT_READ | PROT_WRITE,
               MAP_SHARED, fd, 0);
if (p == MAP_FAILED) die("mmap");
const char a[] = "raw~berries", b[] = "raspberries";
for (size_t i = 0; i + sizeof(a) - 1 <= len; ++i) {
    if (memcmp(p + i, a, sizeof(a) - 1) == 0) {
        memcpy(p + i, b, sizeof(b) - 1);
        i += sizeof(a) - 2;
    }
}
if (msync(p, len, MS_SYNC) == -1) die("msync");
if (munmap(p, len) == -1) die("munmap");
Ważne: sprawdzaj MAP_FAILED, nie NULL. Mapowanie 0 B jest błędem; MAP_SHARED|PROT_WRITE wymaga odpowiednich praw do pliku. Mapa nie musi kończyć się bajtem NUL.

fcntl / O_NONBLOCK · bez zawieszania

↑

Nieblokujące read może dać EAGAIN. Nie oznacza to, że program się zepsuł.

PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
Prosto: O_NONBLOCK już przy otwarciu
int fd = open(path, O_RDONLY | O_NONBLOCK);

PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
Po otwarciu: fcntl zachowuje stare flagi
int flags = fcntl(fd, F_GETFL);

    die("fcntl F_SETFL");
ŹLE: fcntl(fd, F_SETFL, O_NONBLOCK), bo nadpisujesz inne ustawialne flagi. DOBRZE: odczytaj stare flagi, użyj flags | O_NONBLOCK. Po EAGAIN przejdź do poll.
POLLFIFO · 19

poll · czekanie na wiele deskryptorów

↑

Rdzeń L2. events to to, czego chcesz; revents to to, co się stało.

PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
Jedno wejście, 3 sekundy
#include <poll.h>
struct pollfd p = {
    .fd = STDIN_FILENO,
    .events = POLLIN,
    .revents = 0
};
int n = poll(&p, 1, 3000);
if (n == -1) die("poll");
if (n == 0) puts("Minęły 3 sekundy bez danych");
else if (p.revents & POLLIN) puts("Można czytać");
WERSJA ODPORNIEJSZA · FRAGMENT DO WKLEJENIA
Dwa FIFO z EINTR i obsługą HUP
struct pollfd p[2] = {
    { .fd = fd1, .events = POLLIN, .revents = 0 },
    { .fd = fd2, .events = POLLIN, .revents = 0 }
};
for (;;) {
    int n = poll(p, 2, 3000);
    if (n < 0) {
        if (errno == EINTR) continue;
        die("poll");
    }
    if (n == 0) {
        puts("Timeout");
        continue;
    }
    for (int i = 0; i < 2; ++i) {
        if (p[i].fd < 0) continue;
        if (p[i].revents & POLLNVAL) die("POLLNVAL");
        if (p[i].revents & (POLLIN | POLLHUP | POLLERR)) {
            /* na O_NONBLOCK read aż do EAGAIN lub EOF */
            /* po EOF: close(p[i].fd); p[i].fd = -1; */
        }
    }
    /* warunek wyjścia: oba fd zamknięte */
}
poll zwraca liczbę deskryptorów z revents, nie liczbę wiadomości. POLLHUP może wystąpić razem z POLLIN, więc najpierw opróżnij strumień. Zwykłe pliki dyskowe są niemal zawsze „gotowe”, więc poll na nich nie jest przydatny.

PROSTY WZORZEC · SKRYPT TERMINALA

C: open FIFO + sprawdzenie typu

Wiadomości w kawałkach: parser linii

↑

Jeśli protokół mówi „jedna wiadomość to linia zakończona \n”, musisz ją sam złożyć.

PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
Prosty bufor na 1 FIFO
char line[128];
size_t used = 0;
/* Wykonuj na KAŻDYM odebranym bajcie c: */
if (c == '\n') {
    line[used] = '\0';
    printf("Otrzymano: %s\n", line);
    used = 0;
} else if (used < sizeof(line) - 1) {
    line[used++] = c;
} else {
    /* pełny bufor: potrzebna obsługa za długiej linii */
}
WERSJA ODPORNIEJSZA · FRAGMENT DO WKLEJENIA
Odporniejszy parser z odrzucaniem zbyt długiej linii
typedef struct {
    char line[128];
    size_t used;
    int discard;
} Parser;
static void parse_bytes(Parser *p, const char *buf, size_t n) {
    for (size_t i = 0; i < n; ++i) {
        unsigned char c = (unsigned char)buf[i];
        if (c == '\n') {
            if (!p->discard) {
                p->line[p->used] = '\0';
                printf("Wiadomość: %s\n", p->line);
            } else fprintf(stderr, "Za długa/binarna linia\n");
            p->used = 0;
            p->discard = 0;
        } else if (c == 0 || p->used >= 127) {
            p->discard = 1;
        } else if (!p->discard) {
            p->line[p->used++] = (char)c;
        }
    }
}
Dla pięciu FIFO potrzebujesz pięciu struktur Parser. Fragmenty z różnych deskryptorów mogą przyjść naprzemiennie. Nie współdziel jednego used dla wszystkich.

Zadanie próbne · format przepisu 2048 B

L1: FILE* versus fd + obsługa fclose

↑

Jeśli na zadaniu pojawią się funkcje biblioteki C, nie mieszaj bezmyślnie dwóch API.

PROSTY WZORZEC · FRAGMENT DO WKLEJENIA
fopen, fgets, ferror, fclose
FILE *f = fopen("tekst.txt", "r");
if (!f) { perror("fopen"); return EXIT_FAILURE; }
char line[256];
while (fgets(line, sizeof(line), f)) {
    fputs(line, stdout);
}
if (ferror(f)) perror("fgets");  // EOF nie jest błędem
if (fclose(f) == EOF) {
    perror("fclose"); return EXIT_FAILURE;
}
FILE* jest buforowanym strumieniem stdio; fd to mała liczba typu int. fprintf(fd,...) jest błędne, bo fprintf oczekuje FILE*. Nie używaj feof jako warunku przed pierwszą próbą czytania.
